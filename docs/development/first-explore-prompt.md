# Brief for the First Explore Session

Read CONTRIBUTING.md, the product goals, the ADRs, the research overview and the relevant original findings. For a single interactively logged-in test account, work out the smallest verifiable backup including an offline read test. Keep reported reproductions, code/mock evidence and open live questions apart.

Which comparison detects which loss? Draft a verification table with reference source, failure case, user warning and residual risk. Take into account passkey keys and counters, legacy/blob items, attachment IDs, sync freshness and organization boundaries. Outline how to handle temporary plaintext, aborted runs and colliding archive targets on all target platforms.

Question Go and age. Name open decisions, prioritize one synthetic experiment and propose a narrowly scoped first change with acceptance criteria. Stay in Explore. End the session with questions for review, without changing files or writing product code.
