# Releases

Vor einer Veröffentlichung Rechteinhaber und Lizenz klären und LICENSE ergänzen. Drittanbieterhinweise prüfen. Es existieren noch keine Produktartefakte. Vor einem ersten Release Plattformtests, Offline-Leseprobe, bekannte Einschränkungen und geprüfte bw-Version dokumentieren. Verteilung und Signierung sind offen.
