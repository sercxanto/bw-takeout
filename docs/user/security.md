# Sicherheit

Das Archiv wird Passkey-Schlüssel und andere hochsensible Daten enthalten. Schlüssel getrennt vom Archiv aufbewahren. Wer Archiv und Schlüssel besitzt, kann die geschützten Inhalte lesen. Der Umgang mit temporärem Klartext und Abbruchresten muss vor dem ersten Release festgelegt und getestet werden.
