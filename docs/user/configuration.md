# Configuration

There is no configuration file yet. Until there is one, the flags of `bw-takeout backup` are the configuration: the server, the target, the recipients file, and optionally the `bw` executable and a certificate authority file. See [usage](usage.md#making-a-backup). One run backs up one account.

The format of a configuration file is open. It is planned together with several accounts and batch operation. Server and account mapping, archive target, key management and proxy settings need to be documented then. There are no binding configuration keys yet.
